Processing Pipeline

What happens when a lead sends a message:

1
session_store.py → Retrieve or create session from MongoDB
2
language.py → Detect language (Hindi / Hinglish / Kannada / English)
3
lead_scorer.py → Calculate score delta (+15 interest / -15 rejection)
4
emotion.py → Analyze 5-axis emotion state
5
memory.py → Build context (full history or summary + recent 20)
6
objection_handler.py → Check KB for deterministic response
7
llm.py → Generate Gemini response with memory + tone
8
session_store.py → Save response + score to MongoDB

3-Layer Anti-Hallucination

In financial services, AI making up facts = legal liability.

📋

Layer 1: KB Override

5 objection categories with multilingual responses. Fires BEFORE the LLM — 100% compliant.

🛡️

Layer 2: Guardrails

System prompt forbids false commissions, investment advice, and deal closing.

🤝

Layer 3: RM Handoff

AI never closes deals. Score > 60 triggers automatic RM handover.

💬 User: "mera broker better hai"
🤖 AI: "Aapka already broker hai, samajh sakta hoon. Par Rupeezy mein brokerage sharing zyada milti hai. Compare karke dekhein?"
